# Finora

A responsive personal finance dashboard built with React, Vite, and Tailwind CSS.

## Features

- Track income and expenses with categories, amounts, and dates.
- Filter and search transactions for the selected month.
- View live income, expense, balance, category, and spending trend summaries.
- Set monthly category budgets and see overspending warnings.
- Persist finance data and light/dark theme in local storage.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build.
